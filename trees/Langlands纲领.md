## 观念

Langlands 纲领是[调和分析](调和分析.md) ([Fourier 变换](Fourier变换.md)) 的 "非 Abel" 类比.


|                                                           |     |                     |     |                                           |
| --------------------------------------------------------- | --- | ------------------- | --- | ----------------------------------------- |
| [椭圆曲线](椭圆曲线.md)                                                  | ←   | Ramanujan           | →   | [自守形式](自守形式.md)                                  |
| ↓                                                         |     |                     |     | ↓                                         |
| $\operatorname{Gal}(\overline{F}/F) \to {^LG}$, Frobenius | ←   | 原始 [Langlands 对应](Langlands对应.md) | →   | $\mathbb G(\mathbb A_F)$ 的[自守表示](自守表示.md), Hecke |
| ↓                                                         |     |                     |     | ↓                                         |
| 曲线上的平坦 ${^LG}$-丛                                          | ←   | [几何 Langlands 对应](几何Langlands对应.md) | →   | [主丛的模空间](主丛的模空间.md) $\mathrm {Bun}_G$ 上的 Hecke 特征层 |
| ↓                                                         |     |                     |     | ↓                                         |
| $\mathrm {Loc}_{^LG}$ 上的导出范畴                              | ←   | 范畴 Langlands 对应     | →   | $\mathrm {Bun}_G$ 上的 [D-模](D-模.md)导出范畴          |
