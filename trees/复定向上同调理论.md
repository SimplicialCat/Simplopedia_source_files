## 定义

对于[环谱](环谱.md) $E$, 称其**复可定向**是指 $E^2(\mathbb{C}P^\infty)\to E^2(S^2)$ 为满射; 其**复定向**是 $E^2(\mathbb{C}P^\infty)$ 的元素.





## 性质

### 陈类

[环谱](环谱.md)的定向是第一[陈类](陈类.md)的推广: 环谱 $E$ 的定向给出一个同构 $E^*(\mathbb CP^\infty)\simeq E^*(*)[t](t.md)$. 由此可以定义 $E$-值第一陈类 $c_1^E=t$. $E$-值第一陈类与线丛的张量积满足
$$
c_1^E(L\otimes L') \simeq f(c_1^EL,c_1^E L'),
$$
其中 $f$ 为交换环 $R=E^{\text{even}}(*)$ 上的[形式群律](形式群律.md). 另外, 此时 $t$ 是 $\mathbb{C}P^\infty$ 上万有线丛的 [Thom 类](Thom类.md).

### 形式群律

$R$ 上的形式群律等同于 $\operatorname{Spec}R$ 到形式群律模叠 $\operatorname{Spec}L/G$ 的映射.

| 谱 (上同调理论)    | $\operatorname{Spec}L/G$ 上的拟凝聚层 |     |
| ------------ | ------------------------------- | --- |
| 环谱 (乘性上同调理论) | $\operatorname{Spec}L/G$ 上的仿射概形 |     |
|              |                                 |     |

### 阻碍理论

复定向可视为 $\mathbb{C}P^1 \to \Sigma^{2} E$ 到 $\mathbb{C}P^\infty$ 的提升; 而每一步 $\mathbb{C}P^n$ 到 $\mathbb{C}P^{n+1}$ 的[阻碍](阻碍.md)落在 $\pi_{2n+1}E$ 中.

特别地, 若 $E$ 是偶环谱, 则 $E$ 有复定向.

## 例

普通交换环对应的 [Eilenberg–MacLane 谱](Eilenberg–MacLane谱.md)都有复定向结构.

[KU](KU.md) 带有典范的复定向, 称为 Bott 元素 $\beta = [\mathcal O (-1)] - 1$.

[KO](KO.md) 不是复定向上同调理论.
