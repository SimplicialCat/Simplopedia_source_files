## 观念

**质料集合论** (material set theory) 是将集合以 "属于" 关系 $\in$ 描述的理论. 一个集合由属于它的东西完全决定; 两个集合之间也可以谈论属于关系. 于是全体集合可以排成累积层级:

- $V_0 = \varnothing$,
- $V_{\alpha + 1} = P(V_\alpha)$,
- $V_{\lambda} = \bigcup_{\alpha < \lambda} V_\alpha$ ($\lambda$ 为极限序数)),
- $V = \bigcup_{\alpha} V_\alpha$.

与此相反, [**结构集合论**](结构集合论.md) (structural set theory) 中, 集合是一个有结构的范畴 "集合范畴" 的对象, 一个集合由其与其它集合之间的映射决定; 谈论集合之间的 "属于" 关系是没有意义的.
